Access › Setup Wi-Fi password

This is the password of the WallOfText-Setup network, which appears only during setup or when the Pi loses your Wi-Fi. Changing it re-keys that network. 8 to 63 characters.

Access

The passwords are stored as plain text on the Pi and typed over plain HTTP on your home network. Treat them as a household lock, not strong security.

Forget this Wi-Fi?

The printer will leave your home network and disappear from it until it's set up again. It will start the WallOfText-Setup network and print a setup slip.
